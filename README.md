# Network Troubleshooting Lab

A self-built case study demonstrating layered network diagnostics for one of the most common IT support scenarios: a user reporting "no internet access."

## Objective

Simulate a real troubleshooting workflow using standard command-line tools to isolate whether a connectivity issue originates at the device, the local network, or beyond, rather than guessing at a fix.

## Tools Used

- ipconfig
- ping
- tracert
- nslookup

## Case Study

See [network-troubleshooting-case-study.md](network-troubleshooting-case-study.md) for the full investigation, including command outputs, findings, and resolution.

## Notes

This is a solo-built simulation lab. Sensitive network details (hostnames, device identifiers) have been redacted from screenshots for privacy.
